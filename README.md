# Verktyg i textilslöjden

Digital lärobok för årskurs 6 och 7. Webbplatsen använder samma struktur och stilmall som [Verktyg i slöjden](https://exenors.github.io/slojdverktyg-ak67/).

Öppna index.html i en webbläsare. Webbplatsen består av statiska filer utan byggsteg eller externa beroenden. För GitHub Pages publiceras webbplatsen från huvudgrenens rot.

Demonstrationerna har GIF-filer för nedladdning och motsvarande MP4-filer för spelarens paus, hastighet, tidslinje och bildsteg. Filerna har samma motiv. Foton är beskurna ur de nio inskickade bilderna. Symåttets foto är spegelvänt för läsbarhet.
